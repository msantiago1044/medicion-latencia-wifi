# 🌡️ Mapa de Calor de Latencia WiFi

Aplicación web para medir la latencia de tu conexión WiFi en diferentes ubicaciones y generar un mapa de calor interactivo.

## ✨ Características

- 📍 Medición de latencia en tiempo real
- 🗺️ Mapa interactivo con Leaflet
- 🔥 Mapa de calor basado en latencia
- 💾 Almacenamiento local de mediciones
- 📤 Exportación de datos a JSON
- 📱 Diseño responsive
